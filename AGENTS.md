# Aurelle Estates

React + strict TypeScript + Vite. Routes and shared layouts live in `src/App.tsx`; typed sample records are in `src/data.ts`; pure domain logic and schemas are in `src/logic.ts`. Keep database/API operations behind service modules when adding live integrations.

Use the supplied logo in `public/images/aurelle-logo.png`. Its sampled orange is #D55B0A and navy is #003467. Dark orange text uses #8F3500 for contrast. Never replace the logo with generated artwork. No gradients.

Preserve semantic HTML, labelled inputs, visible keyboard focus, reduced motion, responsive layouts and truthful loading/error feedback. Do not invent availability, testimonials, contact information or successful deliveries. Sample content must stay visibly identified.

Run lint, typecheck, unit/component tests, production build and Playwright. Use the four responsive widths in the E2E suite. Keep secrets out of the browser and repository. Never persist or log agent banking, BVN or identity documents until a separately reviewed secure backend is in place. Use private storage and RLS for sensitive records. Do not run destructive database operations without explicit authorization.
